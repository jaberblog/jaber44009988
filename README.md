# CamShare — اشتراک دوربین با وای‌فای

گوشی A (فرستنده) دوربینش را پخش می‌کند و گوشی B (گیرنده) تصویر زنده را می‌بیند.
هر دو گوشی باید به یک مودم وای‌فای وصل باشند.

## گرفتن APK با GitHub
1. یک مخزن (repository) جدید بسازید و همه‌ی فایل‌های این پوشه را (از جمله پوشه‌ی `.github`) در شاخه‌ی `main` آپلود کنید.
2. تب **Actions** → workflow با نام **Build APK** اجرا می‌شود (یا Run workflow بزنید).
3. بعد از اتمام، در انتهای صفحه‌ی اجرا در بخش **Artifacts** فایل `CamShare-debug-apk` را دانلود کنید و `app-debug.apk` را نصب کنید.

## طرز استفاده
- گوشی A: «فرستنده» → اجازه‌ی دوربین → «شروع ارسال» → آی‌پی نمایش‌داده‌شده را ببینید.
- گوشی B: «گیرنده» → آی‌پی گوشی A را وارد کنید → «اتصال».
- روی کامپیوتر هم می‌توانید آدرس `http://IP:8080` را در مرورگر باز کنید.

## نکته‌ها
- برنامه‌ی فرستنده باید روی صفحه باز بماند (صفحه روشن می‌ماند).
- اگر اتصال برقرار نشد، در تنظیمات مودم گزینه‌ی «AP Isolation / Client Isolation» باید خاموش باشد.
